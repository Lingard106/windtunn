## 直接读取

sl_ready/train.npz、validation.npz、test.npz已按原始trusted_training_mask筛选。仅保留X、y_command_g、t_s和episode_id；不包含评价真值。sl_ready/metadata.json保存特征顺序、单位、标签符号及导出文件SHA256。

```python
import numpy as np

with np.load(
    r"D:\WindTunnelSuite\guidance_sim\outputs\expert_dataset\initial_sl_v1\sl_ready\train.npz",
    allow_pickle=False,
) as data:
    X = data["X"]                 # (2806, 31), float32
    y = data["y_command_g"]       # (2806, 2), float32
    episode_id = data["episode_id"]
    t_s = data["t_s"]
```

X在专家决策前记录，包括：视觉估计的所选目标相对位置、理想自身速度/姿态、实际控制比力、上一条指令、检测光线、有效及锁定状态、观测年龄、飞行时间、声明的参考偏移。真实风、真实目标和未来轨迹不进入X。

y顺序为[俯仰,偏航]，单位g，符号向下/向右为正；表示专家限幅后的非重力比力请求，不是已经实现的过载，也不是舵角。姿态矩阵rotation_WL按行展开，满足v_W=R_WL·v_L，即把机体系向量变换到世界系；列名见manifest.json。输入和标签在同一控制决策时刻对齐，执行发生于标签记录之后。

未做标准化；后续若使用标准化，统计量只能在train拟合，再应用到validation/test。不要重新按行随机拆分。当前导出只含有效专家决策，未来NN仍需保留目标不可用时的显式控制门控，不能假设这些样本已教授失锁处置。

## 原始数据与质量

train/、validation/、test/每架次一份原始NPZ，包含完整决策记录、有效/可信掩码及独立eval_*评价字段。eval_*不能作为策略输入。manifest.json记录所有随机工况、特征说明、逐回合结果、版本和源码/配置哈希；report.json为汇总，independent_audit.json为独立检查记录。

唯一失败train_00037：172帧中仅1帧检测、0帧接受目标，专家始终等待有效视觉目标；96条原始记录均无有效及可信标签，未进入任何SL导出。失败已保留，未用零指令冒充正确专家标签。

71个成功回合到所选目标的平均误差1.243mm、最大1.682mm；物理靶仍按原30mm半径判定。全部回合执行约束通过，最大实际控制比力0.106434g，最大变化率2.500000000000018g/s仅含浮点舍入。冻结的0.25g上限、0.10s响应、2.5g/s变化率、重力和阻力保持开启。

这是固定靶局部扰动下、使用理想自身状态及静态CAD先验的初始数据集；没有训练NN。当前目录由Git忽略，协作时需单独传递数据及manifest、审计和元数据。
