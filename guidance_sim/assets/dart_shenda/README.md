# 参考镖体运行资产

整理日期：2026-10-21。以 [manifest.json](manifest.json) 为正式数据源，目录含 124 个 `meshes/dart_*.obj`，清单记录总计 351,782 个三角面。默认加载关系见 [assets 总览](../README.md)。

来源为深大参考装配 `三角翼制导镖.STEP`，实际原件在 `local_originals/制导镖机械图纸/`；清单中的 `source.path` 仍是迁移前旧路径。本次核对原件大小 54,052,141 字节、SHA256 与清单一致。它尚非用户自有镖体的实测模型。

清单同时保存可视网格、估计质量/重心/惯量、参考几何量、镖头位置、相机估计安装和源坐标变换。输出长度单位是米，镖体局部轴为前 / 左 / 上，原点采用估计重心；网格已完成坐标变换，加载时不应再次按源毫米坐标处理。

各 OBJ 只用于外观，关闭碰撞与自动质量贡献。0.25 kg 质量、重心/惯量分配、相机光心和视场等仍有估计项；CAD 未自动产生经过标定的气动系数。物性和相机来源限制保留在清单的 `physics.provenance`、`camera.provenance` 中。

交接须保留清单与全部 124 个 OBJ 的相对目录。本次只核对清单引用文件存在和源 STEP 哈希，没有验证实物尺寸、质量、相机或气动。
