# WindTunnelSuite 开发日志

## 何时写

- 每次会话完成**实质工作**（求解实验/bug 修复/渲染出片/数据分析）后，收工前写当日日志
- 用户说"写日志 / 记一下今天 / devlog"时调用
- 当日已有文件则把新条目插到 `## 本日条目` 标题下（最新在最上）；无则创建

## 位置与格式

文件：`<套件根>/devlog/YYYY-MM-DD.md`（套件根 = 本 skill 所在仓库的上两级，即 WindTunnelSuite/）

每条目格式（追加制，最新在上）：

```markdown
### HH:MM <一句话标题>
- 变更: 改了什么文件/配置（相对路径）
- 实验: 跑了什么（档位/步数/关键数字——从 fan_diag.csv / vtk 实测提取，不凭记忆）
- 结论/发现:
- 待办: （如有）
```

## 规则

- **数字必须真实**：Q/速度/转矩等从 fan_diag.csv、vtk 或 log 实测提取
- **与记忆区分工**：devlog = 按天开发流水；ZCode 记忆区 = 跨会话经验提炼——重要发现两边都写（devlog 记过程，记忆区记结论）
- 引用产物用相对路径（如 `fluidx3d/vtk/`）
- 当日多次实验合并写一条大条目也允许，但标题时间取最后一次
