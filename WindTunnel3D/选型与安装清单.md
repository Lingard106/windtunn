## 1. 分层清单（按功能，含开源优先级）

### L1 · GPU 动态求解（真实雷诺数）—— ★ fluidX3D【开源 · 首选】
- **是什么**：最快的开源 LBM 求解器（OpenCL，为 AMD/NVIDIA 优化，作者 Ghader Yousefi）
- **为什么选它**：AMD 卡唯一顺畅的 GPU 气动路线；LBM 天然适合涵道体素几何（我们已有体素化器）；1mm 晶格真实 Re=1.2e5 在显存内
- **安装**（Windows 原生编译）：
  1. Visual Studio 2022 Build Tools（C++ 工作负载，~7GB）
  2. CMake（winget install Kitware.CMake）
  3. OpenCL SDK：AMD Adrenalin 驱动自带运行时 + vcpkg opencl 头文件（或 WSL2 Ubuntu 路线）
  4. `git clone https://github.com/ProjectPhysX/liquidX3D`（实际仓库 fluidX3D/FluidX3D）→ cmake → fluidx3d.exe
- **验证**：`fluidx3d.exe` 自带 benchmark，识别 RX 6650 XT 即成功
- **与本项目衔接**：`tunnel_voxelize` 输出体素 → 转 FluidX3D `.xyz` 几何脚本（我们提供转换脚本）
- 占用：源码+编译 ~2GB 磁盘

### L2 · 生产级 FVM（精细湍流/验证）—— OpenFOAM【开源】
- **是什么**：开源 CFD 事实标准（ESI OpenFOAM v2412 / OpenFOAM.org 12）
- **安装**（二选一）：
  - **Windows 预编译**（ESI 版，解压即用，最省事）：openfoam.com 下载 Windows 包
  - **WSL2 Ubuntu 22.04 + apt**（性能更好，推荐跑批量）：`sudo apt install openfoam`（org 源）
- **验证**：`simpleFoam -help` / 跑 `tutorials` 里的 cavity
- **与本项目衔接**：`tunnel_body.stl` + 测试物 STL → snappyHexMesh 划网格；结果用 ParaView 看
- 占用：预编译 ~3GB；WSL 发行版 ~2GB + OpenFOAM ~2GB

### L3 · 前后处理三件套【开源 · 强烈推荐，通用基础设施】
- **ParaView**（可视化，读 OpenFOAM/fluidX3D/STL/VTK）：winget install ParaView.ParaView，~1GB
- **Gmsh**（参数化网格，脚本化）：winget install Gmsh.Gmsh，~100MB
- **FreeCAD**（STEP→STL 转换/修模，测试物从 STEP 进来用这个）：winget install FreeCAD.FreeCAD，~2GB
- 全部 `winget` 一条命令装完

### L4 · MATLAB 商业插件（可选，降级推荐）
- **Parallel Computing Toolbox 26.1**：✅ **已于 2026-09-12 安装**（MATLAB 许可已含 PCT 权益，Add-On Explorer 免费安装）。注意: AMD GPU 无法用于 MATLAB gpuArray (CUDA-only)，PCT 在本机只提供 parfor 多核并行 (6 核) — GPU 加速继续走 FluidX3D
- gpuArray 路线判死：AMD 无 CUDA
- MATLAB 与 OpenFOAM/fluidX3D 的联动走文件（mat/stl/xyz），不需要插件

### L5 · 商业软件体验（免费学生版，可选）
- **ANSYS Discovery Student**（免费下载）：实时 GPU 仿真实景，快速对比/演示用；学生许可限制网格数
- **Simcenter Star-CCM+**（学术申请）/ **COMSOL**（无免费版，LiveLink 联动 MATLAB 是它的卖点）：需要付费/学术资质，本项目暂不依赖

### L6 · ROM 降阶模型（场景秒出结果）
- 用现有 `lbm_result.mat`/`flow3d_result.mat` 参数-响应对训练
- 开源路线：Python + scikit-learn（免费）；MATLAB 路线需 Statistics/ML 工具箱（付费）
- 放在 L1/L2 跑批量样本之后做

## 3. 安装顺序（选定后执行）

**第 1 步（所有组合通用，~10 分钟）**
```
winget install Kitware.CMake
winget install Python.Python.3.12        (可选)
winget install ParaView.ParaView
winget install Gmsh.Gmsh
winget install FreeCAD.FreeCAD
```

**第 2 步（组合 A/B：fluidX3D）**
- 路线甲（Windows 原生）：VS2022 Build Tools → vcpkg opencl → cmake 构建
- 路线乙（WSL2）：`wsl --install Ubuntu-22.04` → apt 装依赖 → git clone + make（需 AMD WSL OpenCL 支持）
- 编译完成后跑自带 benchmark 确认识别 RX 6650 XT

**第 3 步（组合 A：OpenFOAM）**
- 优先 ESI Windows 预编译包；若跑批量切 WSL2 apt 源

**第 4 步（衔接）**
- 新增 `export_fluidx3d.m`：把 `tunnel_voxelize` 的体素导出为 FluidX3D 几何脚本
- 新增 `read_openfoam.m`：把 OpenFOAM 结果读回 MATLAB 出图（或直接 ParaView）

## 4. 显存/网格容量速查（fluidX3D, RX 6650 XT 8GB）

| 晶格 | 全涵道格点数 | 显存(FP16) | 物理意义 |
|---|---|---|---|
| 8mm | ~0.9M | <0.5GB | 冒烟 |
| 4mm | ~3.9M | ~0.6GB | 快速 |
| 2mm | ~31M | ~2.5GB | 接近真实 Re |
| 1mm | ~250M | ~19GB ⚠️ 超显存 → 需 1/4 域或 FP16+分块 | 真实 Re=1.2e5 |
| 结论 | **2mm 档（Re~6e4）是 8GB 卡的甜点** | | |
