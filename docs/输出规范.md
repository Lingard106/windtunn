# 输出文件规范

更新日期：2026-10-21。适用于当前源码；路径均相对于 `guidance_sim/`。历史结果目录和数据契约保持原样，索引见 [outputs README](../guidance_sim/outputs/README.md)。

## 默认行为

普通仿真窗口、传统控制及简化导引的无窗口运行、底层 `dart_demo.py` 默认不写输出文件；无窗口结果打印到控制台。当前入口不导出图片。窗口显示、真实相机识别和内存回放不属于文件输出。

## 显式保存

| 入口或操作 | 必要文件与位置 | 开关和边界 |
|---|---|---|
| 通用窗口“保存结果” | `outputs/runs/viewer_<时间戳>.json` | 每次点击只写一份当前状态、完整数值/飞控/视觉配置；不自动导出 CSV 或轨迹 |
| 曲线窗口“导出CSV” | `outputs/exports/` 下 CSV | 仅主动点击时保存；没有 PNG 导出 |
| `traditional_control/run.py` | 指定目录内 `result.json` | 仅 `--headless` 且显式 `--output` 时保存；批量运行逐发更新同一结果文件 |
| `prototypes/ideal_guidance_sim.py` | 指定目录内 `result.json` | 仅 `--headless` 且显式 `--output` 时保存 |
| `prototypes/dart_demo.py` | 指定目录内 `result.json` | 仅显式 `--output` 时保存；该入口本身无窗口 |
| `four_shot_demo/run.py` | `--output` 指定的单个 JSON 文件 | 仅显式 `--headless --output` 时保存；这里的输出参数是文件路径 |

前三个数值运行入口的 `--output` 是目录路径。只有同时指定 `--trace` 和 `--output` 才收集并保存详细逐步轨迹：传统控制写 `<变体>_<种子>_trace.json`，简化导引和底层入口写 `trace.json`。传统控制与简化导引的 `--trace` 还要求 `--headless`。默认不累计或保存这些详细轨迹；交互窗口的回放、曲线仍使用内存记录。

专家策略和参考点微调启动器不再附带默认输出目录。结果 JSON 已内嵌生效配置，普通运行不另写多份配置文件；飞控或视觉配置的主动应用、配置导出属于显式配置管理操作。

## 专家数据采集

采样器运行本身即表示采集数据，默认目录为 `outputs/expert_dataset/<UTC时间戳>_<随机后缀>/`；`--output` 可指定不存在或为空的新目录，`--dry-run` 只打印计划。

一次采集只保留 `train/`、`validation/`、`test/` 中的每回合 NPZ 和一份 `manifest.json`。配置快照、逐回合元数据、源码哈希、完成状态和最终 `summary` 都在 manifest 内；不再额外写 `collection_config.json`、`vision_config.json`、`aim_reference_config.json` 或 `report.json`。中断时保留已完成回合和 manifest，状态及错误以 manifest 为准。

## 交接与保管

新实验使用新输出目录，避免重写同名结果。历史 JSON、NPZ、CSV、图片、说明和报告仍按原目录保管，不用当前规范倒改历史证据。根 `.gitignore` 忽略 `guidance_sim/outputs/`，需要随交接包单独备份。
