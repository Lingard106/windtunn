# 工作区交接总览

交接基准日：2026-10-21（北京时间）。根目录：`D:\WindTunnelSuite`。

## 先了解哪些部分

这是一个以 Windows 本地 Python 环境运行的仿真工作区。运行代码、运行网格、历史结果与原始机械资料分开保存。六个启动器按用途更名，根目录保留两个常用入口，其余四个放在[启动器目录](../启动器/README.md)；它们引用的源码和配置位置保持不变。

```text
WindTunnelSuite/
├─ README.md                         接手导航
├─ docs/                             交接、环境、清单、整理记录及原 README
├─ 运行传统控制仿真.cmd               常用仿真入口
├─ 采集专家示范数据.cmd               数据采集入口
├─ 启动器/                           四个对照与实验入口及更名表
├─ 控制策略与OpenMV_STM32移植说明.md   既有专题说明
├─ firmware_examples/                四份固件参考示例及 README
├─ Guidedemo/                        后续加入的实际 STM32 工程及原有构建目录
├─ local_originals/                  大型赛场原件与机械 CAD 原件
└─ guidance_sim/
   ├─ requirements.txt              四项锁定依赖
   ├─ .venv/                        本机 Python 3.11 环境
   ├─ prototypes/                   共用仿真、UI、视觉、传感器与诊断
   ├─ traditional_control/          独立传统增强分区
   ├─ pn_expert_v2/                 简化模型专家代码与参数
   ├─ learning/                     参考设置与数据采集
   ├─ four_shot_demo/               整理期间并行新增的演示实现
   ├─ profiles/                     运行配置
   ├─ assets/                       运行必需网格及 manifest
   ├─ reference/                    来源元数据
   └─ outputs/                      六组历史基线及并行新增的演示资料
```

## 阅读顺序

1. 看[环境与运行](环境与运行.md)，确认使用项目 Python，而非系统默认 Python。
2. 看[仿真工程 README](../guidance_sim/README.md)，根据入口进入对应目录的 README。
3. 需要历史证据时，从 [outputs 索引](../guidance_sim/outputs/README.md) 找到具体报告；先读其范围、配置和时间，再看数字。
4. 接手固件示例时，读[固件 README](../firmware_examples/README.md)与[原移植说明](../控制策略与OpenMV_STM32移植说明.md)。
5. 交付资料时，用[文件清单](工作区文件清单.md)确认代码、资源、历史结果和 CAD 都已覆盖。

## 文档维护规则

每个主要部分的 README 记录用途、关键文件、依赖与边界。新增入口同步更新根 README、[环境与运行](环境与运行.md)和对应部分 README。新增结果目录随附 README，说明日期、入口、配置、报告路径及是否为中间结果。旧结果保留原 manifest 与配置；清理或移动资料时追加整理记录与前后路径。
