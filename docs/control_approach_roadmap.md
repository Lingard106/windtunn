# 控制方案路线 — swarm 端到端 RL vs 经典参数枚举 (方案记录与推荐)

> 2026-10-16 | 整理: CFD 侧 (曼波方案记录) | 读者: 视觉/算法侧、电控
> 状态: 方案级记录, 非 gate 文档; 接口规范仍以 `guidance_loop_dev_spec.md` 为准。
> **结论先行**: 不是二选一, 是先后问题 — **B (参数枚举) 作主线保底先交付电控,
> A (swarm RL) 作 M4+ 增益层**, 两者共用同一气动环境与 Monte Carlo 评估器,
> 对外接口不变。推荐路线见 §3, CFD 侧对 A 的硬约束见 §4。

## 1. 两个方案

**方案 A — swarm 集群端到端 RL**:
大量镖 (同一 MJCF 模型 × 数百~上千并行 MuJoCo 环境) 训练命中策略
(域随机化: 初值/风/质量惯量摄动/视觉延迟), 期望端到端覆盖控制策略;
策略蒸馏成电控可跑形式 (查表化 / 多项式 / 小型量化网络), 电控参与拟合验证。

**方案 B — 经典控制参数枚举**:
控制结构固定 (外环比例导引 PN + 内环姿态 PID, spec §4.5.2 双环),
对参数 (PN 系数 N / Kp Ki Kd / 延迟补偿项) 网格枚举 + Monte Carlo 打靶筛选,
得到的控制律 (即参数组) 直接交付电控。

## 2. 关系与差异

| 维度 | B 参数枚举 | A swarm 端到端 |
|---|---|---|
| 交付时效 | **快**: 结构现成, 枚举+1000 发 MC 单机过夜 | 慢: 并行 env/reward shaping/蒸馏/HIL 全套 infra, 月级 |
| 中途风险 | 低 — 到 M3 必有可交付物 | 高 — 任何一环卡住 (reward/蒸馏/HIL) 零交付 |
| 扰动泛化 | 限于枚举时给定的扰动族 | 域随机化下泛化上限更高 (swarm 采样优势) |
| 可解释性 | 高 — 因果链可追溯 (舵饱和? 攻角失速? 视觉丢失?) | 黑盒 — 出问题只能重训或归因困难 |
| 电控形态 | 参数组, C 直译, MCU 无压力 | 蒸馏产物 (查表/多项式/量化 NN), 需 HIL 验证 |
| 验收 | spec M2/M3 现成指标 (命中率/CEP) | 无现成指标 — **需要 B 的基线才能证明 "更好"** |
| 依赖 | aero_table.csv + monte_carlo | **同左 + monte_carlo 作为 reward/验收核心** |

关键观察: **A 的每一帧训练都要气动环境仿真** (MuJoCo 注入查表气动力),
reward 的命中判定/脱靶量就是 monte_carlo 评估器 — 那是 B 线的产物。
两条路线的第一步是同一件事: CFD 扫气出 aero_table.csv。**气动侧工作不因路线之争阻塞。**

## 3. 推荐路线 (三步走)

```
Step 1  B 主线 (现在 → M3)
        气动表扫气 → Phase 0 环境闭环 → PN+PID 参数枚举 → M2/M3 验收
        → 控制律交付电控 (保底交付物, 随时可给)
Step 2  A 增益 (M4+)
        swarm RL 训练: 以 B 基线为对照 + §4 硬约束进 reward
        → 蒸馏成电控可跑形式 → 电控在环 (HIL) 拟合验证
        → 通过则替换/增强 B 参数; 不通过 B 兜底
Step 3  黑盒封装 (贯穿)
        对外只留面向目标的接口: Detector/Guidance 类签名 (spec §4.4/4.5)
        + aero_table 查表 — 两方案共用同一环境与评估器, 切换零改接口
```

即曼波概括的链条 **气动环境 → 控制 → 面向打靶的鲁棒性**:
B 把链条每一段做实且可验收; A 在实了的链条上做端到端优化, 蒸馏回可部署形态。

## 4. CFD 侧对方案 A 的硬约束 (训练前必须进 reward/终止条件)

1. **气动可信域出域保护**: 策略机动若把状态扫出 aero_table 可信域
   (V∈[15,30] m/s, α∈[−5°,15°], 出域插值未标定), 仿真里查表 clamp 后照常给 reward —
   策略会学会利用出域区的"物理谎言", 上实物直接翻车。
   **出域必须 reward 惩罚或 episode 终止** (约束值随表元数据交付)。
2. **舵机约束进 reward**: 速率 300°/s + 行程 ±20° (spec §4.2) 越界惩罚 —
   防学出电控执行不了的极端机动。
3. **动导数补偿层同样必须**: Cmq/Cnr 静扫表不含 (spec §4.5.1), MuJoCo 6DOF 无自动阻尼;
   不加阻尼短周期模态震荡, RL 会学出高频抖舵抑制 — 蒸馏到电控即废。工程值在 M3 前标定。
4. **视觉延迟 66 ms 建模训练期常开** (spec §3): 否则策略依赖零延迟假设, 实机必炸。
5. 蒸馏验收对照 B 基线: 同一 monte_carlo (同扰动种子) 下 CEP 与命中率不劣化才允许替换。
