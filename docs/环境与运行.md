## 新电脑重建环境

原环境来源为 Windows Python 3.11.9，当前 pyvenv.cfg 的基础解释器位于原用户目录。虚拟环境包含本机路径，应在新电脑重建。现有环境可用时无需覆盖。

```powershell
Set-Location 'D:\WindTunnelSuite'
py -3.11 -m venv guidance_sim/.venv
.\guidance_sim\.venv\Scripts\python.exe -m pip install -r guidance_sim/requirements.txt
.\guidance_sim\.venv\Scripts\python.exe -m pip check
```

需要带 Tkinter 的 Python 3.11。包版本以 [requirements.txt](../guidance_sim/requirements.txt) 为准；安装所需网络和驱动环境应在接收电脑检查。本次没有安装或升级任何依赖。

## 故障定位顺序

1. 启动器提示找不到 Python：检查 `guidance_sim/.venv/Scripts/python.exe`，按上文重建环境。
2. 缺包或版本不一致：使用项目 Python 运行 pip check，与 requirements 比对。
3. 配置或网格找不到：从工作区根目录进入，按 [profiles](../guidance_sim/profiles/README.md)、[assets](../guidance_sim/assets/README.md) 与 manifest 核对文件。
4. UI 或渲染异常：记录入口、终端错误、显示环境和复现步骤；元信息检查通过仍需要实际窗口验证。
5. 历史结果与当前行为不同：确认入口、配置快照、源码哈希及报告日期一致，再判断是否有变化。
